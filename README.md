# ✊ Stone Paper Scissors Game

A simple and interactive **Stone Paper Scissors** game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and see who wins!

## 🚀 Features

- 🎮 Play against the computer.
- ✊ Choose Stone, 📄 Paper, or ✂️ Scissors.
- 🤖 Computer generates a random choice.
- 🏆 Automatically detects the winner.
- 📊 Displays game results instantly.
- 🎨 Simple and user-friendly interface.
- 📱 Responsive design (if implemented).

## 🛠️ Tech Stack

- **HTML5** – Structure of the game.
- **CSS3** – Styling and user interface.
- **JavaScript** – Game logic and interactivity.

## 🎯 Game Rules

| Player Choice | Computer Choice | Result |
|---|---|---|
| Stone | Scissors | Player Wins |
| Paper | Stone | Player Wins |
| Scissors | Paper | Player Wins |
| Same Choice | Same Choice | Draw |

## ⚙️ How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Select Stone, Paper, or Scissors and start playing!
